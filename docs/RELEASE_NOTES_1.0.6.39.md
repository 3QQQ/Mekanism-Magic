# Mekanism Magic 1.0.6.39 — 精简自然灵气与禁忌界面

这是实际修改界面运行时代码后的新 `.39`，不是此前仅版本元数据变化的旧包。
经用户确认，旧包已经原样归档；详见 [旧编号记录](history/RELEASE_NOTES_1.0.6.39_WITHDRAWN.md)。

## 界面

- 读数卡不再常驻显示“灵气、燃料余量、核心等级、储存等级”等说明标签，
  只保留实际数值、等级、必要状态值和进度。原说明及精确数据合并到悬停提示中。
- 底部长状态条改为右下方的 14×14 信息图标，悬停查看完整工作状态和异常原因。
  机器标题、顶部关键状态和操作按钮文字保留。
- 移除森林仪式台与修饰处理界面的“材料、辅料、产物”字样；
  森林仪式的材料、树苗、金粉和产物空槽补上悬停说明。
- 默认深浅科技主题和可选 AE Terminal 主题均应用相同的精简布局。
- 不改槽位、物品、权限、配方、能耗或经验存取算法。经验仍显示等级，
  1级/10级/全部存取按钮保留，经验仓不增加经验条。
