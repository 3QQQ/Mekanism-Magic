# 普通 AE2 图样供应器的单面物品投料

配方机器向普通 AE2 图样供应器公开 `AECapabilities.CRAFTING_MACHINE`。
供应器仍是 AE2 原方块，无须在机器里安装 Mek Energistics 样板升级。
AE2 会将完整处理样板、整批物品和接触面一起交给机器；机器先规划全部输入，
再一次性提交。输入面关闭、槽位不足、配方角色无法确定或材料不符合样板时整批拒绝，
供应器继续保留订单。

## 接线与样板

1. 将普通图样供应器贴在机器的一个物品面。默认是顶部 `输入/输出`；使用其他面时，
   将那个面的**物品**配置设为 `输入/输出`，并按需要关闭其余物品面。
   部分机器的普通 `输入` 类别不包含激活物、献祭物等专用输入槽。
2. 从本模组机器 JEI 的有效产物页录入处理样板。附魔、绑定、法术和配方上下文随样板保留；
   数据相关配方从实际物品按 `U` 进入，再录入样板。
3. 给机器供给它原有的魔源、灵气、能量等资源，并保留输出空间。
   也可直接接入 AE 并开启单机“AE 自动供给”，从网络能量与魔法存储补充；资源节点需要频道。
   默认物品自动弹出开启时，产物可从同一复合面进入相邻供应器并返回 AE 网络。
4. 配方要求的常驻配置先按原机器规则准备，例如灵体来源、催化剂库、仪式选择器、全典和粉笔。
   不消耗的配置物品不应写成每次加工都消耗的样板材料。

装有 JEI 与 AE2 时，本附属的机器页为 Offering、Tree Ritual、Animal Spawner、Clibano、
赫菲斯托斯锻炉的普通物品/护甲转化、灵魂提取、模拟血液提取和经验装瓶显式提供
“转移到样板编码终端”。录入的是页面**当前显示**且经实时配方复核的消耗物品与
确定性物品产物：Offering 每批主料与一次启动物；Tree 的原料、树苗和 16 金粉；
Animal 的原料与实际刷怪蛋；Clibano 的主料与必得成品；锻炉的主辅料与对应组件的
普通物品产物；三种制备机的物品投入与固定产物（灵魂提取含确定的沙子副产）。
页面上的火种、核心、锤、增强器、工具、捕捉样本和凋零玫瑰是保留的机器条件，
四种精华、存血量和经验也不伪装成可投递物品；概率残渣或奖励不声明为必得输出。
核心升阶改的是机内常驻核心，无法作为待回网物品录入；Aura 燃料和 FE→Aura
也没有固定物品主产物。自然祭坛原有的签名化上下文转移另行保留。仅桥接本附属
机器页，不复制原模组世界结构页的加工语义。缺少当前输入、组件与产物不符或终端
格数不足时会在录入前提示，不写入不准确的样板。

样板终端本身的输入格数限制保持有效。超过其可表示的不同物品数时，JEI 会拒绝录入。
普通供应器一次交给机器的是完整物品批次；本入口不接受流体或其他 AE 资源键。

## 分槽与数量

- 普通单输入机和工厂使用各自公开的加工输入槽，保留槽位的物品限制与容量。
- 奥术附魔装置的九格无序识别试剂与副材料。
- 催化标识装配器及动物生成机将 AE 合并的重复物品重新拆入各自需要的独立样本格。
- 仪式引擎按所选仪式将激活物、献祭物和普通材料分开投递。
- 供奉、树木仪式、双输入燃烧机及赫菲斯托斯锻炉依据完整配方将主、副材料投至专用槽。
  同一种物品在两个角色中使用时也会拆分数量。
- 有固定角色的复杂配方按一次逻辑操作编码；AE CPU 可以反复下发同一样板。
  额外堆成多次操作的复杂样板会安全拒绝，不新增隐藏缓存。
- 赫菲斯托斯核心升级的产物仍留在持久核心槽，不能作为普通供应器等待回网的加工产物；
  此类升级样板会拒收。普通物品仪式使用正常主、副材料入口。

这条路径不创建新的机器 AE 节点，也不扩大持久槽或手动槽的外部提取权限。
机器自身的原生资源节点属于独立功能；它未激活时仍可使用本地资源接受普通供应器的整批物品。
普通物品管道继续使用原来的逐槽物品能力。

## 验证

```powershell
.\gradlew.bat runExternalProviderGameTestServer '-Pmekanism_magic.ars_runtime=true' '-Pmekanism_magic.arseng_runtime=true' --offline --no-daemon
.\gradlew.bat runForbiddenGameTestServer '-Pmekanism_magic.occultism_runtime=false' --offline --no-daemon
```

专用测试使用真实的普通 AE2 图样供应器、AE CPU 与存储盘，检查单面物品发送、角色槽位、
精确产物回网，以及错误面、关闭面、错误材料和堵塞时不接收部分批次。
测试世界与普通客户端存档分开。

`1.0.6.55` 验证结果：外置供应器专项 12/12、禁忌集成 111/111，`check` 与完整打包校验通过。
