# Mekanism Magic 1.0.6.14（未发布开发版）

## ME 魔力存储磁盘

新增五档磁盘，可装入 AE2 的 ME 驱动器或 ME 箱子。同一张盘共享容量存放魔源和
自然灵气，不把魔法资源伪装成物品、流体或 FE。

| 磁盘 | 字节数 | 单一资源最大存量 |
| --- | ---: | ---: |
| 1K | 1,024 | 1,024,000 |
| 4K | 4,096 | 4,096,000 |
| 16K | 16,384 | 16,384,000 |
| 64K | 65,536 | 65,536,000 |
| 256K | 262,144 | 262,144,000 |

- 每字节 1000 单位，每种资源单独向上取整，共用字节池，最多 63 种资源。
- 支持原生元件工作台的资源分区；未分区时接收已适配的任意魔法资源。
- 灵气保留原生类型 ID；主世界、下界、末地及其他类型不因存盘互相转换。
- 安装 Ars Énergistique 时直接使用其原生 SourceKey，与已有魔源盘、ME 魔源罐
  及网络保持同一魔源条目；未安装时由本模组提供魔源键，不再强制依赖 Ars Énergistique。
- 内容与分区按稳定资源 ID 保存，不依赖可选模组的 AE 键序列化。暂时缺少资源提供
  模组时，其内容不显示为可用库存，但原数量、分区与占用容量仍保留。
- 支持模拟存取、保存回调、拔盘和物品存档；非空盘（包括暂不可用资源）不能嵌套进
  普通物品存储盘。不存在把魔源或灵气转换为另一资源的存取捷径。

合成使用对应等级的 AE 存储组件 + AE 物品存储外壳 + 紫水晶碎片，无序合成。
本版不提供用旧盘参与的升级/拆解配方；容量迁移不通过把非空盘当作普通合成材料实现。
迁移容量时使用 AE 原有网络/IO 传输流程，保留空盘本身。物品外观复用 AE 的磁盘
纹理体系并染为浅紫灰色，状态灯保持 AE 原生逻辑，驱动器内保留各档位外观。

## 魔法资源标识器与接口

标识器用纸 + 紫水晶碎片无序合成，可重复使用：

1. 手持标识器，在空中右键切换资源；潜行右键反向切换。
2. 将标识器点击到 ME 接口的配置槽，设置想维持的资源；初始需求为 1。
3. 点击该槽的 AE 原生齿轮按钮，设置保有数量。
4. 用魔力管道从接口抽取，再传给机器；反方向可用管道把机器资源输进接口，再由
   接口自动送入网络磁盘。只存入网络时无需提前设置接口保有数量。

标识器仅携带零数量的筛选标记，不拥有真实魔力，不产生资源，也不能给容器充能。
魔源与灵气可以占用同一个接口的不同槽位。自有魔法类型每接口槽的容量为 256,000
单位；Ars Énergistique 魔源类型沿用其注册的原有容量。

灵气接口按所在世界的原生灵气类型工作。即使网络跨维度，也不能用下界接口把
主世界灵气当成下界灵气抽出。原有机器侧面配置、管道方向和传输限制仍然生效。

已有支持 AE 接入的 Ars 机器可直接从新盘自动补充魔源。灵气机器通过
ME 接口 → 魔力管道 → 机器的原有灵气能力输入输出；本次没有把所有灵气机器
另加原生 AE 节点，也不改其侧面配置。

## 扩展边界

本版实际接入 Ars Nouveau 魔源与 Nature's Aura 注册的灵气类型。其他魔法模组
不会因名字中带“魔力”而自动支持。后续适配可在公共初始化阶段调用可选 AE 集成的
`MagicResourceKeys.register(resourceId, name, icon)` 注册资源，并通过同一 canonical
key 接通对应传输能力。注册名必须稳定，不可随本地化名称变化。

核心 ItemStack 组件为 `mekanism_magic:magic_cell_contents`，其中 `amounts` 是
资源 ID → 正整数 long 的映射，`filter` 是资源 ID 列表。未知资源照原样保留，
不会因缺少提供模组而自动删除。所有 AE 查询、枚举、插入、提取使用同一个运行时
canonical key；自有键对主键身份进行弱驻留，符合 AE 对引用身份的索引要求。

  重装、终端枚举与取出数量一致；AE primary-key 引用身份已覆盖回归。

  核对盘内余量；现有德格米原生 AE 节点的显式与自动补魔源路径均通过。

  长整数边界、非空盘不可嵌套、零数量标识不造能且误放真实库存不丢失。
- `check assemble validatePackagedIntegrations`（要求完整可选集成）通过。
