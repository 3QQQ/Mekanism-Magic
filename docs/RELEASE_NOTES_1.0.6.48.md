# Mekanism Magic 1.0.6.48 — 自然灵气与禁忌机器界面收紧

此包是未发布的主开发树测试包。修改运行时界面尺寸与真实菜单背包偏移，同一轮从
`1.0.6.47` 递增一次至 `1.0.6.48`。没有修改机器注册 ID、配方 ID、
存档键、用户自定义名称或之前交付的 1.0.6fix、.46、.47 修复包。

避免两处 UI/容器高度漂移。

## 验证

- `check -x jar -x validatePackagedIntegrations` 通过；离线皮肤自测绘制
  默认暗/亮主题与可选终端暗/亮主题，并检查标题、读数和底部背包。
- Nature-only 真实 GameTest 67/67 通过，机器菜单契约核对 15 台已注册
  自然灵气机器的卡片、按钮和背包槽位。
- Forbidden 游戏环境最初因为默认附带 Occultism 却未加载其前置而在模组加载阶段退出；
  使用独立的 Forbidden 配置关闭这项无关运行时依赖后重跑，120/120 通过。
  第一次启动未运行测试，不计作通过。
- 仍需玩家在客户端实际查看所有界面，尤其不同屏幕比例、资源包与高级工厂侧栏展开效果；
  本轮没有将服务器/离线预览当成客户端视觉验收。

新的本地测试包包含开发树其他尚未发布的自然灵气、禁忌及魔法资源存储内容，
不作为 1.0.6fix 范围的维护发布包，也未上传到任何远端。
