# 1.0.6.62 — 独立 AE 配置与锻造台槽位内收

相对最后有效运行时代码基线 `1.0.6.61`，本轮新增独立 AE 配置页、服务器权威分项开关与
对应实际传输控制，并将锻造台的容器槽在客户端内收。这些是实质运行时代码改动，
完成验证后开发编号只递增一次；不改正式发布号，不覆盖历史包。

## 界面

- 锻造台三个精华容器槽从右侧移至工作区中部，保留统一风格、原有槽位对象、索引、
  输入输出权限和服务端坐标。关闭界面恢复原槽；背包、增强器侧栏和四种精华读数不变。
- 普通机器与六类工厂共享独立 AE 侧栏入口；原侧面配置内的 AE 按钮改为打开同一窗口的快捷入口。
  预留包括隐藏警告在内的侧栏占位，避免后续警告出现时相互覆盖。
- 只显示本机适用的功能。未安装 AE 或不适用的机器隐藏入口；共用代码不直接依赖 AE 类。

## 开关语义

- 补给：能量、魔源、灵气、耀金／灵魂／血液／经验精华。
- 回网：物品、流体、魔源、灵气和四种精华。
- 两个方向各有总开关，关闭总开关不清除分项选择。旧存档的关闭补给只影响补给，
  新的回网开关默认开启。配置随存读、掉落物及工厂升阶保留，暂缺 AE 时仍保留。
- 服务器校验菜单、玩家权限、实际世界机器身份和按钮白名单；客户端不自行修改设置。
- 不删除库存、样板、既有作业或节点，不伪造断线。已有付费队列、退款与保留余额继续安全结算。
- 不新增样板／自动合成开关，不改样板定义、发现与投递。关闭某类回网时，该类产物留在机器；
  依赖这个出口的合成订单会等待交付，重新开启或以其它合法方式搬运后继续。
- 覆盖原生普通出口、魔法资源出口、矿机／德格米旧出口及 MekE 物品／流体出口，
  保持单节点归属与原有物理输出回退。
