# Mekanism Magic 1.0.6.52 — 按催化剂种类扩展自然灌注保留槽

自然灌注单机、标准工厂及 Mekanism Extras 工厂仍保留原来的两个物理催化剂槽，
但额外容量不再固定。当前数据包的祭坛配方会展开物品、标签和多选催化剂并按物品
及组件去重；多于两种时，在原“保留催化剂”面板内出现扩展槽，每页最多显示 16 格。
原版 41.9 只有两种，因此默认不显示额外空槽。对展示候选不完整的自定义
Ingredient，保留一个供实际匹配材料进入的探索空槽；是否能用仍按配方的
`Ingredient.test` 判定。

配方重载使种类减少时，已有催化剂及原槽位保留、可取回，空槽随新目录缩减。
分页视窗不改变固定菜单结构；配方选择、AE 精确样板与工厂自动平分读取完整库，
不会随玩家翻页改变。旧 `.50` 单槽和 `.51` 双槽的世界 NBT/机器物品均有索引迁移，
拆机作为物品携带再放置、基础级升级到无限级也保留扩展库内容。

验证：自然灵气专用服务器 GameTest 77/77 通过，包括新增第三种催化剂、26 种
催化剂分页、缩容保物、旧世界/机器物品迁移及升级；完整离线 `check`、
机器标题及侧栏/面板自测通过。尚未进行真实客户端视觉目测。

本轮相对 `1.0.6.51` 有实质运行时代码变更，仅递增一次开发号到 `1.0.6.52`。
这是本地开发测试包，不是正式发布。
