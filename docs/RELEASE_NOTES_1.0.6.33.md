# Mekanism Magic 1.0.6.33（未发布开发版）

## 机器名称与界面标题

参考各原模组的语言文件和手册，为附属机器统一命名；完整名单见 [机器命名表](MACHINE_NAMING.md)。
例如森林仪式台、降生培育舱、诸神祭祀台、德格米共生舱、魔源谐振器、克里巴诺秘炉。
名字保留原版辨识词，同时对应附属机器实际功能；不是覆盖原模组本体的名称。

- 覆盖 47 台机器（23 台独立机器＋三系列八档工厂）的中英名称和默认 GUI 标题；管道名称保留。
- 补齐此前缺失的 8 台机器的 container 标题键。Mekanism 默认菜单标题使用该键，
  仅有物品/block 翻译并不能保证 GUI 标题正确。
- 普通机和六类工厂界面统一调用 `MagicThemedScreen.drawMachineHeader`，普通机标题也默认置于
  y=4 的标题带内。长标题滚动，标题末端和状态标记之间保留四像素间隔。
- 不改机器注册 ID、配方 ID、存档、成本、内部加工或自动化规则，不覆盖玩家自定义名称。
- `AGENTS.md` 和新增机器文档记录默认命名/标题要求；`validateMachineContracts` 拒绝缺失、
  不一致或占位名称，`testMachineTitles` 检查所有机器的中英名称、七个共用标题入口及长标题布局。

这次是名称与界面代码变更，开发号只递增一次。历史 `.32` 测试包保留，未发布、上传或重启用户客户端。
完整重启后使用新标题栏；本轮自动化检查未声称已进行客户端画面验收。
