# Mekanism Magic 1.0.6.12（未发布开发版）

德格米新增三个固定产物映射：

| 收容实体 | 新增产物 |
| --- | --- |
| 坚守者 | 回响碎片 |
| 海龟 | 海龟鳞甲 |
| 犰狳 | 犰狳鳞甲 |

- 回响碎片是本模组新增的可再生产出规则，并非原版坚守者的死亡掉落；原版幽匿催发体产出保留。
- 鳞甲原本通过生长、活体掉落或刷取获得，本轮补入德格米特殊产物规则。
- 每种匹配实体类型每次模拟固定产出1个。堆叠升级仅按实际操作倍率放大一次，最高256倍；放入多个同种生物容器不重复增加该固定产量。
- 数据包也将相同产物加入普通掉落池时，特殊产物先从随机候选中移除，避免重复计数。
- 继续遵守德格米实体黑名单和物品黑名单；不恢复装备、马铠等杂项。原下界之星与荒野贡品规则不变。
- 可通过 `mekanism_magic:drygmy_special_loot/echo_shard`、`turtle_scute`、`armadillo_scute` 实体类型标签调整来源，不给无关生物添加奖励。

本轮保留此前功能与修复，未自动发布。
