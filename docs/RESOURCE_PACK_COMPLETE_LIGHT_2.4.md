# AE Terminal Complete Light 2.4：原包文字方案

本次仅为独立资源包补充文字字体。没有修改模组运行时代码、`mod_version`、
用户实际游戏设置或存档，没有重新构建模组 JAR。2.0–2.3 历史包保留。

## 变更范围

用户要求“文字也按原先的方案进行”，并保留此前“不增加客户端补丁”的约束。
因此使用所提供 CozyUI+ 的 MCsans+ / NotoSans 位图文字方案，而不添加文字配色补丁。

- 新增 `assets/minecraft/font/default.json` 和 `uniform.json`。
- 每套定义保留原有顺序的 9 个文字／UI 符号 provider，排除 10 个 emoji provider。
- 7 张 `mcsans_05_*.png`、2 张 `ui_05_*.png` 原样复制。
- 原图字高、基线、字符网格、alpha 和字宽标记不变；不重绘、调色、增粗或去除低透明像素。
- 两套定义共用同样的 9 张图；41,524 个唯一字符映射。原字体低优先级回退仍由游戏管理。
- 不导入语言文件，不改变物品名称或附魔文本，不给已有文字主动增加 UI 符号。
- 原生白／灰字、阴影算法、Mek / AE2 文字色表保持原状。
- 2.3 的全部 1,571 个 `assets/` 条目逐字节不变，包括 JEI 原生尺寸与稳定 UV 修正。

PNG 和原始 JSON 存入独立 `cozyui-text-font-source.zip`，未改写此前 GUI 源快照。
原始字体 JSON 含注释；构建器只解析并排除表情 provider，不改剩余 provider 参数。
SIL OFL 1.1 字体授权及原包作者来源仍随包保留。

## 验收方法

静态校验检查源 ZIP 哈希、原始字图字节、两个 provider 定义、每行字符数、图格尺寸、
授权文件、既有 UI 资源不变、JEI 资源集合和历史包哈希。

字体字宽按当前 Minecraft 1.21.1 `BitmapProvider` 的 alpha 扫描规则计算，
包括原图 alpha=1 的字宽标记；客户端通过实际加载的 `FontSet` 检查 111 个样本文字在
default / uniform 下的 advance、ascent、像素尺寸、图格位置和逻辑字高，共 222 次匹配。
样本覆盖中英文、数字、常用标点、罗马数字、无穷符号和原 UI 私用字符。

独立客户端中文环境下检查真实选项页、暂停菜单、视频设置、世界列表，以及原生物品提示。
JEI 使用项目现有 `19.39.0.369`，分别进行冷启动和从原生界面热重载的验收，
检查创造背包侧栏、合成、熔炼和酿造页面；热重载要求全部 45 个 JEI 图集条目的 UV 不变。
所有客户端只使用 `build/` 下测试设置与临时世界；测试夹具不进入资源包或运行时 JAR。

首张原字体表存在原包已有的重复字符定义，Minecraft 按原顺序的最后一项解析。
本次未擅自去重／重排；字宽计算和客户端比对使用相同规则。日志中的相应重复定义警告
不等于字体加载失败，具体字形结果以实际客户端指标与截图为准。

本次验收结果：静态检查、222 项真实字体指标、5 个中文原生菜单、JEI 冷／热两组均 PASS。
GUI scale=2、窗口 1720×1000；已查看字体／提示、菜单及 JEI 截图。
原始参考 ZIP 不可用时，解压源材料包后仅使用缓存输入，仍可逐字节重建同一安装 ZIP。
安装包 30,027,871 字节，SHA-256：
`aec2d0c004cdedb2773b2a503554b209ea9f96881a165123632e7bf88dca348b`。

## 产物

- `dist/resourcepacks/AE-Terminal-Complete-Light-2.4.zip`：游戏安装包。
- 同名前缀 `-source.zip`：可离线重建的输入与工具，不用于游戏启用。
- 同名前缀 `-checks.json`：静态、真实菜单和 JEI 验收汇总。
- 同名前缀 `-client.json`、`-jei-hot.json`、`-jei-cold.json` 及截图：原始验收记录。

仅用 2.4 替换旧界面包并置顶；加载过旧错误版本的进程应完整退出游戏后再启动一次。
模组自己指定的其他字体、硬编码文字颜色及所有辅助模组的组合界面不在全面实测声明内。
