# Mekanism Magic 1.0.6.25（未发布开发版）

## 按 Mekanism 原版默认档位重整加工功率

本轮参考本地 Mekanism 10.7.19.85 的 UsageConfig 默认值，对普通加工、合成编码、魔法反应与资源采集分档，不把所有机器统一成同一功率。共享定义位于 `MagicMachineEnergyProfiles`，所有值都是 **J/工作tick**。

这是本模组的固定平衡参考，不动态绑定用户对原Mek `machine-usage.toml` 的修改；Mek速度/能量升级公式及J/FE换算仍沿用当前配置。原版没有这些魔法机器，功能对应属于本模组设计，不宣称是原模组魔法配方自带的FE价格。

| 档位 | J/t | 默认FE/t | Mek参考 |
| --- | ---: | ---: | --- |
| 材料加工 | 50 | 20 | 熔炉、富集仓、粉碎机、冶金灌注 |
| 合成编码 | 100 | 40 | 自动合成机；本模组三材料锻造也归此类 |
| 魔法反应 | 200 | 80 | 提纯、化学灌注/氧化等加工档位 |
| 复杂锻炉 | 400 | 160 | 化学压射、结晶等高阶加工档位 |
| 资源采集 | 1000 | 400 | 数字矿机基础档位，不凭空叠加精准/范围罚价 |

## 工厂统一单工位基数

- 三类工厂（魔灵、魔源灌注、自然祭坛），普通与Extras共24档，全部采用每个工作工位50 J/t＝默认20 FE/t。
- 注册能源属性也统一为单工位基数，实际总耗电由正在工作的工位及实际operation数相加，不重复乘工位数。
- 3/5/7/9/11/13/15/17工位全开、无升级且每工位一次operation时，总功率为60/100/140/180/220/260/300/340 FE/t。
- 原能源容量与Extras原容量供应链保持不变，不因降功率丢失已有电量；GUI继续显示实际消耗。
- 德格米和维度矿机旧待加工任务加载时，按已准备的批次数和恢复后的升级重新计算剩余工作的电价。保留旧随机产物、进度、Source费用及身份，不重抽、不追收此前已消耗的能量。

## 明确保留的部分

- FE魔源转换器保持基础500 J/Source（默认200 FE/Source）；FE灵气转换器保持基础20 FE/Aura及原Aura→FE回流保护。
- 灵气场接口保持上轮修正的20 FE/Aura；FE魔源增强器仍按原生产事件计费，不套加工机档位重新定价。
- 燃料灵气发生器和魔力管道不新增FE消耗。
- 不改配方时长、储能、魔源/灵气数量、原版增强物、工厂数量、Ars纯魔源慢速分支或上一版的红石停机/真实能耗计量。
- 未发布，不启动用户游戏；继续通过IDEA后台检查项目代码。
