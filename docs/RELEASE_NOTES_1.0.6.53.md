# Mekanism Magic 1.0.6.53 — 自然灌注界面与均分回归

根据无限自然灌注工厂的实机截图，修正三处问题：

- “配方”切换原先占用左侧 `y=84..102`，遮住 Mekanism 自动均分标签绘制在
  `y≈86..101` 的开/关文字。现在改为右侧书本图标标签，与催化剂及红石标签分行。
- 原排序器只有找到当前催化剂可启动的配方才均分；未放催化剂时即使原料合法，
  也会停在首工位。现在允许无催化剂的普通祭坛原料先均分到空闲工位，仍排除
  运行中、带配方锁或 AE 精确上下文的工位，并检查输出槽兼容性。
- 原版仅两种催化剂且无扩展槽时，“保留催化剂”弹窗改为与其他保留槽相同的
  62×42 两格紧凑面板；数据包确有额外催化剂时才展开分页网格。真实槽位索引、
  保存键和已有物品不变，重载切换布局时同步移动槽位与视觉边框。

验证：自然灵气专用服务器 GameTest 78/78 通过，新增标准与 Extras 工厂
“64 个灵魂土、无催化剂”的均分回归及 AE 锁槽保护；完整离线 `check`、
机器侧栏/面板布局自测通过。尚未进行真实客户端视觉目测。
