# 独立模型设计记录 V2（原 1.0.6.17 编号已撤销）

历史设计记录已移至本文件；正式接入当前 V4 模型的 `1.0.6.17` 另见对应开发日志。

此文件保留设计过程，不是有效模组版本的发布日志；该轮没有接入游戏或生成对应 JAR。

本轮仅针对自然灵气模型风格反馈制作一台独立 FE 转换器样机，未替换游戏资源或
批量修改其他机器。样机采用一体种荚反应舱、非对称整流组件、汇流支路、分层密封
结构和独立灵气出口，不再复用第一版的祭坛式平台与金顶立柱。

BB 可编辑工程、原生几何导出和两张视口截图保存在
`assets/blockbench/nature_seedpod_v2/`；详见该目录 README。

新增样机几何检查入口；原系列检查器的几何逻辑可作为库复用，原 CLI 严格检查保留。
样机 242 个立方体的 BB/Java 一致性、UV、旋转、单方块边界均通过，可见共面冲突 0。
旧系列 16 项目/16 等级灯状态的校验仍通过。

本轮所有工作通过 Blockbench MCP 后台完成。预览临时开启标准明暗后恢复原设置，
没有桌面鼠标键盘操作。对比 1.0.6.16 JAR，现有八个运行时主结构模型逐字节未变。

因为这是等待确认的设计样机，未制作更换游戏模型的测试 JAR，未发布或更改客户端。
