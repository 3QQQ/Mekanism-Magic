## 产出类型选择与 AE 装瓶

FE 灵气转换器和灵气燃料发生器提供“当前世界／主世界／下界／末地”输出选择。
默认仍跟随所在世界；只有本地 Aura 储槽与已付费燃料额度都为零、且没有进行中的
网络输出时才能切换。实际 Aura 类型随存档和机器物品保存，不把已有资源重标类型。
原本仅适用主世界的花卉燃料限制按所选输出类型判断；不会用花在下界档制造幽灵灵气。

生成机可通过自己的原生 AE 节点输出所选类型至魔力存储盘，需要 AE 频道、自动资源
传输开关以及至少一个允许输出的灵气侧面。普通消费者、灵气场接口和魔力管道仍遵循
各自现有的类型安全规则；场接口不会伪造另一维度的环境，也不强加载其他世界。

每只气息瓶都由一只原生“瓶与塞”（Bottle and Cork）和同类型 `20,000` Aura 构成。
`20,000` 是 Nature's Aura 41.9 实际装瓶扣除量；世界装瓶的 `100,000` 是环境门槛，
不是单瓶资源单价。AE 装瓶不访问世界 Aura，也不凭正 Aura 生成真空瓶。

- 手动操作沿用 AE 的原生容器交互：鼠标持“瓶与塞”左键已存 Aura 行装一瓶，
  `Shift+左键` 连续处理手持堆叠；成品留在光标，堆叠溢出按 AE 规则进入背包或落地。
  持满瓶右键可将瓶内的**同类型** Aura 注回网络并返还空瓶，`Shift+右键` 批量处理。
  空光标不装瓶；没有自定义装瓶网络包或远程序号入口。
- 将任一产灵气机器接入同网并配置 AE 合成 CPU 后，网络原生提供气息瓶的自动加工
  订单；CPU 交付的材料必须严格为一只网络中的原生空瓶与 `20,000` 对应类型 Aura，
  成品回到网络。
- 满仓或中断时的已付款产物/退款进入持久账本；恢复后重试，只交付一次。机器的
  资源收发开关和红石控制不取消这一独立网络装瓶服务的已付款订单。

自然祭坛处理机与工厂本身统一支持原生加工目录，不需要切换主世界/下界来选择产物；
其物品配方仍按原料、催化剂和签名上下文选择，灵气输入仍要求所在地类型。

状态：**里程碑 0—6 与 Mekanism Extras 四级高阶自然祭坛工厂已实现。开发版 `1.0.6.7` 在统一灵气侧面配置页签与窄条槽的基础上，同步收紧主界面和实际背包槽位；`check`、47 个机器资源契约和本轮灵气专项 GameTest 36/36 通过。IDEA 隔离测试世界已经能够进入，先前 GLFW 崩溃未在近期测试中重现；长时间满负载动画与帧率仍待完整验收。**

## 41.9 API 与配方概况

- 世界灵气由 `IAuraChunk` 管理，默认区域基准为 `1,000,000 Aura`，公开区域查询、
  drain、store、最高/最低 drain spot 和 Aura 类型接口。
- 方块与物品储量通过 `NaturesAuraAPI.AURA_CONTAINER_BLOCK_CAPABILITY`、
  `AURA_CONTAINER_ITEM_CAPABILITY` 和 `IAuraContainer` 交互。
- Overworld、Nether、End 与其他维度使用不同 Aura 类型；跨类型传输不得默认混合。
- 数据包中的原生专用配方统计如下：

| 配方类型 | 数量 | 实现状态 |
| --- | ---: | --- |
| `naturesaura:altar` | 36 | 处理机与八级工厂已适配；Extras 四级扩展随本轮联合服务端回归通过 |
| `naturesaura:offering` | 7 | 献祭处理机已适配 |
| `naturesaura:tree_ritual` | 17 | 树木仪式处理机已实现，联合服务端验收通过 |
| `naturesaura:animal_spawner` | 72 | 动物生成处理机已实现，联合服务端验收通过 |

36 条祭坛配方中有 31 条带 catalyst、5 条不带 catalyst。实现必须从当前
`RecipeManager` 动态读取配方，保留输入、输出组件、Aura 成本、处理时间和 catalyst
上下文，不按本次 JAR 的具体物品列表硬编码。

## 设计边界

1. Nature's Aura 是环境资源，不等同于 Ars Source、Mekanism 化学品或流体。
2. 世界 Aura 必须经明确的采集/回注端点进入机器网络；普通管道不能隐式扫描区块。
3. drain/store 必须走公开 API，从而保留 drain spot、维度 Aura 类型和环境影响。
4. FE 只为控制、处理和稳定设备供能；首批不增加无条件 FE → Aura 无限转换。
5. 模型保持单方块范围，沿用独立的自然科技系列；普通工厂正面保留 Mekanism 原版
   等级灯，高阶工厂使用 Extras 原版等级灯纹理与 UV。主体不复制 Ars Nouveau 或
   Occultism 机器，不新增 PNG，也不重复叠加完整法阵。
6. 创造魔力升级只免除本机配方的 Aura 消耗，不把有限储槽变成可向外输出的无限源。
