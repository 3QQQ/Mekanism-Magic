# Mekanism Magic 1.0.6.42 — 微缩法阵启动与通用粉笔显示

## 问题与修复

通用粉笔识别没有被删除：`chalk_rainbow` 和 `chalk_void` 仍能在任意粉笔槽
满足全部法阵颜色要求。此次复现的是启动等待问题，而不是取消了通用粉笔资格。

微缩法阵铭刻台原本每调用一次配方查询才扣一次等待计数，和共享的查询退避叠加，
将预期的 5 tick 等待拉长；每 8 tick 的漏斗式补料又会反复重置等待。
已改为每个服务器 tick 倒计时，并在等待时暂缓查询，不将正常等待标成无效配方。
加工中的合法补料、唯一染料组合校验和按材料扣除规则保持不变。

JEI 之前只展示普通颜色粉笔，现增加彩虹／虚空替代选项与双语悬停说明。
一支通用粉笔可覆盖全部粉笔颜色且不消耗，但配方染料仍须提供。
微缩仪式本身不可堆叠，连续生产需要及时抽走输出；本次不改变这个物品规则。

## 验证

- 两项修复前失败的启动测试在修复后通过：材料齐全后按时启动，以及每 8 tick
  持续补充同一种材料时仍能完成制作。
- 遍历 18 种原生法阵 × 彩虹／虚空／对应颜色粉笔 × 连续两份制作，
  核验正确产物、完整材料扣除和粉笔不损耗。
- 彩虹与虚空各遍历全部 16 个真实粉笔槽，校验手动插入及实际加工；
  缺少普通粉笔颜色时不能制作，补入一支彩虹粉笔后可恢复。
- 核验 JEI 每一种颜色均包含两个通用粉笔替代选项。
- Occultism 1.222.0 与 1.224.2 两套运行矩阵均 77/77 通过，包含上一版
  灌注连续加工、AE／MekE 自动化等回归项。
