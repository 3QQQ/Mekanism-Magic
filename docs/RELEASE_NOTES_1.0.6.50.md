# Mekanism Magic 1.0.6.50 — 恢复自然灌注自动平分

标准与 Mekanism Extras 自然灌注工厂曾主动禁用自动平分：Mekanism 原生排序只
移动物品栈，不同步本附属每条工位的配方锁、进度与 AE 精确样板上下文，可能串配方。

本轮恢复两个界面的自动平分开关及其持久状态，改用配方感知的普通原料平分。
只有配方 ID、签名和输出兼容的工位参与；有精确样板上下文的工位不被移动，
仍保留原有配方锁、进度和剩余件数。没有改动自然祭坛单机或合成配方。

验证：自然灵气专用服务器 GameTest 69/69 通过，其中新增普通原料 3/17 路
平分和运行中 AE 锁定槽保护用例；完整离线 `check` 与完整集成打包校验通过。
正式客户端视觉验收未做。
