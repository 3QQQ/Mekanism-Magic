# 通用粉笔法阵收取核查（主项目 1.0.6.44）

本次针对“通用粉笔画出的法阵无法被空白微缩仪式收取”补充测试，尚未复现反馈中的失败。
没有修改收取、展开、粉笔识别或其他模组运行时代码；`mod_version` 保持 `.44`，没有重打 JAR。

## 验证范围

- 先按原生法阵放置结构，再实际调用 Occultism 彩虹／虚空粉笔的 `useOn` 重画符文。
- 用原生多方块 `validate` 确认结构有效后，才测试空白物品的收取。
- 18 种法阵 × 2 种通用粉笔 × 中央祭祀碗／边缘符文两种点击位置，共 72 个收取场景，
  实际调用空白物品的 `onItemUseFirst`，确认物品转换、原结构清空且不产生重复掉落。
- 巨灵制造法阵另测两种粉笔、四种旋转、两个点击位置的收取→展开→回收，核验符文状态、
  自定义布局、完整结构和材料守恒。通用颜色可能令多个旋转同样满足原生规则，因此
  绘制布局允许整体规范旋转，但不允许个别符文变化或材料增减。
- 既有取消事件、权限、忙碌祭祀碗、已被认领结构和回滚检查一同运行。
- 新增测试只在启用 Occultism 的能耗测试配置中注册，不要求缺席模组的测试运行加载其类。

Occultism `1.222.0` 和 `1.224.2` 两套矩阵均为 **95/95 通过**；IDEA 后台测试文件编译通过。
原始日志保存在 `build/reports/universal-chalk-capture-1.0.6.44/`。
