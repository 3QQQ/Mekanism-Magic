# Mekanism Magic 1.0.6.47 — 附魔配方与反应羊皮纸修复

本地开发修复包，基于 1.0.6fix 的维护内容范围，累积保留 1.0.6.46 的微缩法阵修复。
没有发布到 GitHub 或 CurseForge，没有覆盖任何历史包。
主开发树同步同一修复，但交付 JAR 只从维护工作区构建，不带入未完成的自然灵气、
禁忌、新魔法资源存储元件或接口。

## 修复内容

### 配方选择

- 不再返回最先匹配到的材料子集。当前库存中每一种物品及组件组合都必须参与本次配方；
  同种、同组件的额外数量可作为后续批次库存。
- 在完整参与的候选中优先材料项数更多的配方，避免高级附魔材料被低级附魔抢走。
- 同等优先级存在不同配方或不同产物时停止制作，保留材料；不依赖配方枚举或槽位顺序选择。
- 保留绑定传送卷轴优先作为主材料的原有规则。
- 主材料和副材料使用完整组件匹配。副材料组合必须通过原生 matches/assemble；
  第一个组合被原生规则拒绝后会继续搜索，而不是直接放弃该主材料。
- 同组件库存合并计数，使用容量预检查和有界搜索；无法证明结果唯一时不消耗物品。
- 此规则不猜测尚未投入机器的材料或玩家将来打算做的配方。建议一次投入完整的一批。

已验证原先错误的九条附魔书配方：
保护 II/III/IV、横扫之刃 II/III、深海探索者 I/II/III、击退 II。
保护 IV 不再产出“保护 III＋穿透 I”。

### 反应附魔与 JEI

- 从已写法术羊皮纸查看用途时，把该实物及完整法术组件放入副材料，而非替换成空白羊皮纸。
- 已选中的无效主材料不会被偷偷替换成默认有效材料。
- 空白羊皮纸不能凭空产生法术；同时提供多个冲突的羊皮纸焦点时不生成可编码产物。
- 为 67 条高等级附魔配方补充其前一级附魔书的 JEI 用途检索键。
  这些只是隐藏索引，不会作为未经选择的真实输入或样板产物。
- JEI 与 AE 转移继续按实际输入重新组装、核对输出完整组件；不会只凭同物品 ID 编码。
- 反应 I 到 IV、既有附魔、名称、绑定与法术数据均按原生规则处理。

使用方式：反应 I 的样板从已写好法术的羊皮纸按 U（查看用途）进入机器配方；
高等级附魔使用已有前一级附魔的实际物品查看用途。空白羊皮纸无法制作反应附魔，
这是原模组规则。多张不同法术羊皮纸混在同一批中时会安全停机，请分开投料。

## 验证内容

原生 Ars Nouveau 5.13.0 的 97 条附魔配方逐一对照原生 matches/assemble，
核对精确预览、AE 样板准入及真实机器产物，全部通过。

新增与加强的回归包括：

- 九条冲突配方各轮换九个输入槽位置，结果和配方 ID 一致。
- 保护 IV 两批连续加工，正确消费数量，不降级或误选其他附魔。
- 混放空白与已写羊皮纸、混放不同法术时保持输入，不错误附魔羊皮纸或消耗无关的书。
- 从实际羊皮纸的 JEI 输入选择模型构造样板，完成真实 AE CPU 合成任务。
- 原有反应附魔书 AE 任务、I→IV 连续升级及附魔武器/护甲、绑定卷轴等动态组件测试继续通过。
- 67 条前一级附魔书检索键与实际 stored_enchantments 一致，未泄漏到默认可编码输入。
- 微缩法阵的全部 18 模板、34 种蜡烛、6 种中央仪式碗、通用粉笔、连续加工和法阵捕获回归保留。

使用独立 GameTest 世界，没有操作用户存档或重启用户客户端。
JEI 的输入选择模型与检索键经过运行时测试，AE 任务真实执行；
未宣称进行了用户客户端中的 JEI 点击测试。

测试日志位于维护工作区：
build/reports/ars-apparatus-fix/。
