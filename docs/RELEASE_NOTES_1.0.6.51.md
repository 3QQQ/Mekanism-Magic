# Mekanism Magic 1.0.6.51 — 自然灌注双催化剂与配方选择

Nature's Aura 41.9 自带 36 条自然祭坛配方，其中 31 条需要催化剂，原版仅有
转换与粉碎两种催化剂。原版祭坛在四角缓存催化块，按配方管理器列表找到首条
匹配的输入＋催化剂配方即使用它，不检测或提示多配方冲突。灵魂土是实际冲突：
转换可产恶魂之泪，粉碎可产灵魂沙。

本轮为自然灌注单机、四级标准工厂和四级 Mekanism Extras 工厂增加第二个
常驻催化剂槽，并提供“配方”按钮：当普通投料有多条可用配方时，点击可明确
切换结果。已有 AE/MekE 精确配方按其配方 ID/签名执行，不受按钮覆盖；运行中
的工位不改配方。新槽可用于侧面配置，并加入持久输入列表。

保留原催化剂槽的逻辑 ID；工厂旧世界存档的后续物品槽（含能量物品、样板槽）
按索引迁移，旧机器物品缺少的新槽在原位置插入空项。升级数据保留两种催化剂
及普通投料的配方选择。

验证：自然灵气专用 GameTest 72/72 通过，涵盖原版灵魂土双配方、按钮切换、
AE 精确锁、菜单双槽、旧世界/机器物品迁移和完整升级链；离线完整 `check`
通过。正式客户端视觉验收尚未完成。
