# Mekanism Magic 1.0.0

Minecraft 1.21.1 / NeoForge 正式初版。

## 主要内容

- Mekanism 风格的魔灵处理器与四级魔灵工厂。
- 支持 Occultism 灵火、粉碎、结晶和魔灵交易配方。
- 仪式引擎支持常规物品、召唤、献祭、矿工魔灵和储存升级仪式。
- 微缩仪式制作机支持 18 种五芒星，并可在材料冲突时手动选择目标。
- 维度矿机提供 27 个输出槽、附魔效果同步和高速自动弹出。
- 支持 Mekanism 速度/能量升级、侧面配置、自动输入输出和工作动画。
- 可选支持 Ars Nouveau 收容罐、Mekanism Extras 高阶工厂和 JEI。

## 依赖

- Minecraft 1.21.1
- NeoForge 21.1.194 或更高
- Mekanism 10.7.15 或更高

Occultism 1.222.0 或更高为可选集成；未安装时本模组不会注册游戏内容。
