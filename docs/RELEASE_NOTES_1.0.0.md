# Mekanism Magic 1.0.0

Minecraft 1.20.1 / Forge 正式版。

## 运行环境

- Minecraft `1.20.1`
- Forge `47.4.22` 或更高的 47.4.x
- Java `17`
- Mekanism `10.4.16.80` 或更高的 10.4.x
- Occultism `1.158.0` 或更高的 1.20.1 版本

JEI、Ars Nouveau、Mekanism Extras 与 Mekanism: MoreMachine 为可选兼容目标。

## 主要内容

- Mekanism 风格的魔灵处理器与基础、高级、精英、终极魔灵工厂。
- 支持神秘学 1.20.1 的灵火、粉碎、结晶和魔灵交易配方。
- 支持灵魂宝石、绑定魔灵之书、刷怪蛋及 Ars Nouveau 收容罐。
- 仪式引擎提供 16 个材料输入槽、仪式选择、激活、献祭和单输出。
- 微缩仪式制作机按真实五芒星成型材料和粉笔颜色制作当前版本五芒星。
- 投影平台的异界石与原版石头底层不会计入微缩仪式材料。
- 终极微缩仪式使用原版工作台配方，要求锻造 Marid、附身 Afrit、召唤 Marid、
  召唤野生高等魔灵四个微缩五芒星。
- 维度矿机提供 27 个输出槽、不消耗矿工输入、同步附魔效果并支持自动输出。
- 支持 Mekanism 原生能量槽、侧面配置、工作动画、速度升级和能量升级。
- 安装 Mekanism Extras 时提供绝对、至尊、宇宙、无限四级额外魔灵工厂。

## 修复与整理

- 修复机器组件重复注册导致的工作异常。
- 修复 Forge 1.20.1 魔灵 NBT、矿工标签和配方输入类型差异。
- 修复标题、玩家物品栏、粉笔模块和魔灵全典模块布局与显隐。
- 移除终极微缩仪式自定义配方序列化器，改用原版工作台配方。
- 可选高阶工厂资源仅在 Mekanism Extras 存在时加载。
- 同步中英文机器名称并清理 1.21.1 专用五芒星代码映射。

## 构建产物

```text
build/libs/mekanism_magic-1.0.0-forge-1.20.1.jar
```
