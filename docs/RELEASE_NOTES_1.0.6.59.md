# 1.0.6.59 — 直连 AE 产物回网

本轮相对已交付的 `1.0.6.58` 新增运行时输出事务和资源守恒修复，完成验证后仅递增一次开发编号。
不发布正式版本，不修改历史 JAR、远程标签或发布记录。

## 行为

- 四相精华凝聚器直连 AE 即自动将四种精华存入现有魔力磁盘，不需要额外 ME 接口。
  原版容器装填和可选 PackagedFAA 流体视图保留，三条出口共用实际精华缓存。
- 其它机器和原生/Extras 工厂的真实物品产出也直接回网。物品进入 AE 物品存储，
  魔源凝聚器的实际 Source 与灵气发生器的实际 Aura 进入相应魔力资源存储。
  保留样本、催化剂、工作材料和未装满的精华容器；不反向抽取消费者的魔力缓存。
- 复用机器已有的单个节点，安装 MekE 时复用其物品出口，不添加第二个节点。
  AE 供给开关只控制从网络输入，关闭供给仍可输出。断网、缺盘、分区拒收和满盘时保留产物。
- 先预留实际产物再提交；未接受部分原位退回，无法退回的余额随存档、掉落物及工厂升阶保留。
  同物品的工厂输出槽合并导出，不同产物轮转，避免第一工位持续产出时堵塞后排。
- 外部提交/回退异常及提交中保存的未知提交记录持久化隔离，不盲目退款或重放；
  AE2 的缺失内容占位物不作为真实产物回网，暂缺资源键提供者时原样保留记录。
- 修复精华管道升阶时旧网络重新吸收已领取份额的重复计数；升级负载仅携带本地所有量。
  重复应用同一升级负载不会再次计入资源，同一刻区块卸载/重载可正确归还到保留的网络。
