# Mekanism Magic 1.0.6.13（未发布开发版）

德格米新增一批经过来源核查的活体产物，补齐鸡蛋及同类可采集资源。
物品直接产出，不需要投入桶、瓶、碗或剪刀，也不增加耗材槽。
牛奶等真实流体只按在线 AE 网络的实际接收量直入网络，没有 AE 或容量不足时
不生成桶装、瓶装替代品，不新增储罐、流体槽或流体管道接口。

## 产物范围

默认提供 35 条数据包定义：18 条原版、13 条 EarthMobs、4 条 Occultism。
其中 33 条启用；猫的晨间赠礼和村民英雄赠礼默认关闭，供整合包明确选用。
未安装可选模组时，相应规则不会加载。

## 状态与批次

- 保留成年/幼年、鸡骑士、剪毛标记、蘑菇和染料颜色、苔藓/泥污状态、剩余羊角及
  使魔升级条件；不会仅凭实体名或战利品文件名猜测产物。
- 谜之炖菜保留实体已保存的效果。棕色蘑菇牛被雷击变红后仍可能保存有效效果，
  这种合法红色个体也按保存效果产出；没有保存效果时产蘑菇煲。
- 每条规则按实体类型及有效产物变种去重，同种同变种的重复容器不会重复增加活体
  产量。概率每个变种抽一次，然后仅应用一次实际操作倍率，最高 256 倍；不进入
  普通死亡掉落的数量奖励重复抽选。
- 批次准备后固定抽取结果、操作倍率和资源成本；存档重载及机器恢复按容器签名
  续接待完成批次，处理中更换堆叠升级不会再次放大旧批次。
- 实体只读入内存计算，不加入世界，不运行 AI、真实剪毛或交互回调；不修改收容
  容器、消耗岩浆怪、移除羊角、清空炖菜效果或把蘑菇牛转换成牛。

## 流体与输出

物品使用现有输出槽和 AE 批量输出路径。牛奶从牛奶桶的流体能力或 `c:milk`
解析；蜂蜜从蜂蜜瓶的流体能力或 `c:honey` 解析；熔岩使用 `minecraft:lava`。
这些容器名称只是查找真实流体的依据，不是投入品或产物。没有注册流体提供方时
跳过该流体，龙息和炖菜仍是直接产出的物品。

流体只写入在线、有电、允许该流体且有容量的 AE 存储。无网络或拒收时没有对应
流体产出；部分接收时仅保留已进入网络的数量，不将余量转成桶瓶或可补领储液。
仅有流体而无物品的周期在 AE 没有任何接收能力时暂停，容量预检不预留空间。
有物品产物的周期仍可正常处理物品。

共享 AE 执行预算暂缓首次写入时，已完成并付费的流体批次可持久化等待重试，
不重新付费或生成；实际容量拒绝、部分接收或网络离线则结束该流体输出。
这份待投递记录不提供流体储罐、槽位或管道能力。

## 数据包与兼容边界

规则放在 `data/<namespace>/drygmy_harvest/*.json`，可覆盖同路径、设置
`enabled: false` 或添加独立规则，并在数据包重载时更新。支持显式实体清单、
模组前置、年龄条件、NBT 子集条件和变种键；NBT 可用 JSON 对象，精确字节匹配
可使用 SNBT 字符串，例如 `"{Muddy:true,Sheared:false,Color:9b}"`。

`item` 和原生处理类型支持 `count` 或数量区间；通用 `loot_table` 类型保持
战利品表数量，不能用 `count` 覆盖。规则数、单次物品数、流体量和操作倍率均有
上限，错误定义或不支持的上下文跳过并记录警告。

本轮核查包含 EarthMobs 19.3.0、Occultism 1.222.0/1.224.0，以及 Ars Nouveau、
Productive Bees、Mowzie's Mobs、Aquaculture 和 Nature's Aura 的相关来源。
覆盖是明确列出的有限目录，不宣称自动发现所有模组活体产物。配方型高级蜂生产、
村民交易、猪灵交易、付费材料转换、任意实体背包物品和一次性装备拆取不自动导入。

完整证据、各项原生条件与 JSON 示例见
[活体产物审计](DRYGMY_HARVEST_AUDIT.md)，材料过滤与去重见
[德格米产物策略](DRYGMY_LOOT_POLICY.md)。本轮未自动发布。
