# Mekanism Magic 1.0.6.6（未发布开发版）

## 自然灵气界面统一

- 灵气场接口、自然祭坛处理机、动物生成处理机、全部八级自然祭坛工厂的六面灵气设置，移入已有 Mek 侧面配置窗口的“灵气”页签；主界面不再放置六个方向字母按钮。
- 保留原有物品、能量配置页，不增加另一枚外置配置按钮。灵气使用 Mek 的六面示意、输入/输出/输入输出/禁用颜色；左右键分别正向、反向循环。批量清空或切换只操作灵气，不改变 FE、物品或进度。
- 真正替换旧侧面配置按钮，修正固定窗口重开、调整窗口大小后可能出现重复配置窗口的问题；窗口回调始终绑定当前界面的按钮。
- 前后左右依据机器朝向映射到原有绝对面存储，不改变现有世界的方向数据、灵气内容和 NBT 格式。服务端验证打开的菜单、距离、当前机器及安全权限。
- 灵气槽改用与魔源槽同尺寸的 Mek 原生窄条边框，和 FE 槽并排。填充颜色仍取实际灵气类型，有少量灵气时至少显示一像素。
- 创造魔力升级状态随主菜单同步；灵气槽显示配方无限状态及实际内部缓冲值，不伪造可导出的无限灵气。
- 灵气场接口的吸收/回注/平衡工作模式、动物生成目标选择保持原位。无灵气消耗的献祭、树木仪式机器不添加多余槽位。

新增菜单、八阶工厂、四朝向、单面正反/批量控制、权限/非法操作、方向持久化及资源不变性回归；本轮灵气专项 GameTest 34/34 通过，`check`、47 项机器资源契约与测试源码编译通过。打包检查强制包含新侧面配置和灵气槽实现。
