# Mekanism Magic 0.1.0

本次发布同时提供两个 Minecraft 版本：

- `mekanism_magic-0.1.0-neoforge-1.21.1.jar`
  - Minecraft 1.21.1
  - NeoForge 21.1.x
  - Mekanism 10.7.x
  - Occultism 1.22x
- `mekanism_magic-0.1.0-forge-1.20.1.jar`
  - Minecraft 1.20.1
  - Forge 47.4.x
  - Mekanism 10.4.16.80
  - Occultism 1.158.0

## 主要内容

- 魔灵处理器和基础/高级/精英/终极魔灵工厂。
- Mekanism Extras 可选高阶魔灵工厂：绝对、至尊、宇宙、无限。
- 仪式引擎：16 个材料输入、仪式选择、激活、献祭和单输出。
- 微缩仪式制作机：根据真实五芒星成型材料制作微缩五芒星。
- 终极微缩仪式：四个最高等级 Marid 五芒星的严格工作台配方。
- 维度矿工处理机：不消耗矿工输入、三行九槽输出、附魔和自动输出。
- Mekanism 风格 GUI、能量槽、侧面配置、速度/能量升级和 JEI 分类。
- Occultism 灵魂容器、刷怪蛋、Ars Nouveau Mob Jar 兼容。
- 双版本分别使用对应加载器、NBT、配方和 Mekanism API。

## 已知限制

- 首次发布重点是构建、启动和核心注册验证；建议进入世界后逐台测试机器 GUI、配方和自动化。
- Ars Nouveau、Mekanism Extras、MoreMachine 自身可能产生资源或 JEI 警告，不代表 Mekanism Magic 崩溃。
- 两个 JAR 不能跨 Minecraft 或 Mod Loader 混用。
