# Mekanism Magic 1.0.6.55 — 普通 AE2 供应器单面物品投料

本地未发布开发构建。相对最后有效运行时代码基线 `1.0.6.54`，新增了普通外置
AE2 图样供应器的整批物品能力、共享原子投料器，以及固定主副材料槽的配方分组。
这些是新的运行时代码改动，验证后将开发编号只递增一次到 `.55`。

## 行为

- 普通 AE2 图样供应器直接贴机器的一个已配置物品面即可发送整份处理样板，
  无须在机器中安装 MekE 样板供应升级。默认面仍为顶部 `输入/输出`。
- 普通加工机、工厂和 Extras 工厂共用这一入口。原有槽位限制、容量、物品组件与侧面权限保留。
- 仪式引擎、供奉、树木仪式、燃烧机、赫菲斯托斯锻炉按完整配方将消耗材料分入专用槽。
  催化标识装配器和动物生成机为重复材料保留独立样本格。
- 工厂催化配置在本次整批接收中预检并提交，避免两个供应器在同一 tick 填入相互冲突的催化配方。
- 拒收不会留下部分材料；普通供应器保留订单并重试。输入面关闭后，旧能力引用也不能继续投料。
- JEI 燃烧残渣改为仅展示角色，避免把概率累计副产物声明成每次必得的样板输出。

使用方法和范围见 [单面物品投料说明](EXTERNAL_PATTERN_PROVIDER.md)。持久配置物品按原机器
规则预置；赫菲斯托斯的核心升级产物仍留在核心槽，此类升级不能作为等待物品回网的处理样板。
复杂角色配方按一次逻辑操作编码，AE CPU 可重复下单。
