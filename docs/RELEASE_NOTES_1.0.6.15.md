# Mekanism Magic 1.0.6.15（未发布开发版）

新增两台 Nature's Aura 机器，沿用现有原生灵气槽、侧面配置、升级页及魔力管道。
产物进入机器内部灵气槽，不直接修改世界环境灵气。

## FE 灵气转换器

- 基础最高 **250 灵气/t**，基础 **20 FE/灵气**，即满速 5,000 FE/t。
- Mekanism 内部能量单位是 J；扣费先依现行 FE/J 设置换算，不把 J 错当作 FE。
- 不足 FE 或剩余空间时按可实际产生的整数灵气扣费；不够一单位的余电保留。
- 支持速度、能量升级。GUI 同步实际 FE 单价与本 tick 产量；速度依 Mekanism
  处理时间公式提升速率，能量升级降低耗费。
- 单价最低仍须严格高于 Nature's Aura 当前 `auraToRFRatio`，避免原生灵气→FE
  装置和本机组成正收益循环。原生默认是 20 灵气→1 FE，而不是 1 灵气→20 FE。
- 继承本模组的全方向 FE 输入默认值，灵气侧默认全部输出，可在侧面配置中修改。

## 燃料灵气发生器

无需 FE，不显示无用的充电槽、电量条或能量配置页。两个素材槽可以任意顺序放料；
单独残余输出槽使用现有自动弹出权限。顶部默认物品输入输出。支持速度升级，基础
**1,000 灵气/t**；加速只缩短已付款素材的释放时间，不提高每件素材的总产量。

### 支持的原生素材

来源为本地核验的 Nature's Aura **41.9** 实现，不是将普通可燃物或任意掉落物
编成燃料。实际匹配尊重原生射弹生成表、苔石转换表、小型花标签和物品组件。

| 素材 | 基础总灵气 | 限制／残余 |
| --- | ---: | --- |
| 鸡蛋 | 10,000 | 原生射弹表 |
| 雪球 | 7,000 | 原生射弹表 |
| 火焰弹 | 35,000 | 对应小火球 |
| 末影珍珠 | 50,000 | 原生射弹表 |
| 附魔之瓶 | 200,000 | 整件消耗，不返空瓶 |
| 箭、药箭 | 30,000 | 同为原生箭实体 |
| 光灵箭 | 40,000 | 原生射弹表 |
| 三叉戟 | 3,000,000 | 和原生吸收相同，消耗整件，不只是耐久 |
| 小型花 | 初始 25,000 | 仅主世界型灵气；重复使用同种花有衰减 |
| 原生表中的苔石 | 5,000 | 返还对应洁净方块；41.9 默认四组 |
| 带烟火之星的烟花火箭 | 依烟花组件 | 无星火箭不适用 |
| 含持续正面效果的滞留药水 | 依原生效果 | 普通／喷溅／纯瞬时／无效药水不适用 |
| 远古树叶 | 2,000 | 仅主世界型灵气；返腐败树叶 |
| 湮灭玫瑰 + 末影之眼 | 500,000 | 必须双材料；返枯灌木；末影之眼不能单独发电 |

射弹数字读取 `NaturesAuraAPI.PROJECTILE_GENERATIONS`。苔石表读取
`BOTANIST_PICKAXE_CONVERSIONS.inverse()`，不自行把苔藓块、所有苔石台阶或楼梯
都算进去。

花的产量为 `max(0, 25000 - 100 × 同种疲劳)`；每次消耗该花疲劳 +5，其他花种
疲劳 -1（最低 0）。历史随存档与机器掉落保存；产量降为 0 时不会继续吞掉该花。

烟花按飞行时长和各爆炸星的闪烁、拖迹、形状、主色去重数量计算；渐变色不额外
计入。滞留药水只用第一个持续正面效果，以封闭处理原生新鲜药水云的九次吸收
模拟完整过程，不生成实体或粒子。普通三分钟迅捷为 129,600 灵气，迅捷 II 为
518,400，八分钟长效迅捷为 345,600；极端无效自定义效果会被边界检查拒绝。

远古树叶和湮灭玫瑰带有已序列化的方块实体数据时不作为新满额燃料，防止耗过的容器
再次按初始容量生成。灵气缓存、灵气瓶不是本机燃料；紫颂果、树苗、肉、皮革、
黏液球也不会冒充原生树木或实体生成过程。

### 事务与输出

- 消耗素材时同时记录待释放的灵气总量、余额及原生类型，并处理必要的残余物。
  残余槽堵塞时不吞新素材；灵气满槽、红石暂停或类型不匹配时保留未释放余额。
- 每 tick 只把可放入灵气槽的余额转入，存档、拆机再放置不会重新领取同一件燃料。
- 两台机器均有 **4,000,000 灵气**内部容量、**64,000/t**共享外部输出预算。
  邻接多个方向不会乘倍输出，目标模拟与实际接收不同则处理真实接收量和余量。
- 默认自动送入正常连接的魔力管道、匹配类型的灵气容器或 ME 接口；不必把输出侧
  管道另设为抽取。仍可用管道抽取，和自动输出共用同一 tick 预算。
- 接 ME 接口即可进入上一版魔力磁盘；需要供给原版环境装置时，可再经
  **灵气场接口（释放模式）**转入世界环境。不得跨维度把已存灵气改成另一类型。
- 保留现有全局机器掉落保护与物品输入/输出权限；不为生成器添加 AE 合成样板节点。

本机以内置灵气槽容量代替原生生成器对 35 格环境浓度的暂停判定，不要求地面搭建
原装置或催化器。这是自动化机器的封闭生成机制，不声称逐 tick 重建原版自然环境。

## 界面与资源

两台机器各有独立单方块模型、工作状态、配方、掉落、工具标签和创造栏入口。
沿用 Nature 系列的钢、注灵石和金色部件；FE 转换器为立式转换核心，燃料机为
开口反应腔。模型没有超出单个方块，也没有新增世界粒子或大规模动画。

JEI 新增“原生素材产灵气”类别，显示输入、额外启动素材、残余及基础灵气总量；
花的衰减与烟花／药水的组件条件在提示中说明。燃料机进度条可打开该类别。
