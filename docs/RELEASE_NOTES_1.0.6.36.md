# Mekanism Magic 1.0.6.36（未发布开发版）

## 恢复主工作区槽位

按本轮反馈，以下物品恢复原来的主界面位置，不再放入“常驻组件”侧栏：

- 维度采掘井的矿工组件。
- 德格米共生舱的九个样本。
- 魔灵驱策台及全部八档魔灵工厂的魔灵。

共恢复 11 个机器/工厂菜单。其余需要收纳的辅助组件继续使用侧栏；
恢复后的德格米样本空槽提示保留。只改界面选择，不改库存、物品或自动化权限。

## 统一侧栏边框与留白

新“常驻组件”面板和原粉笔页、辞典页、催化剂库共用布局规则：

- 外框四边均为 2 像素，不再叠加一侧阴影或底部额外装饰条，明暗主题一致。
- 按完整的 18 像素槽框居中计算左右留白，单槽及未满的一行也居中。
- 内容上下、网格与翻页区之间保留 4 像素。侧栏统一从主面板右边加 28 像素处开始。
- 粉笔页为 80×96，辞典页为 62×42；实际槽位置、边框识别及鼠标区域使用相同常量。
- 催化剂库为 98×128，顶部选择框使用 26 像素高的标题区，避免跨过标题带边缘；
  4×4 网格左右居中，按钮对称排列。右键选配方按完整槽框命中，边缘点击不再错位。

原侧栏物理菜单槽的坐标随布局同步更新；逻辑编号、物品归属、分页索引、存储格式、
取放限制和关闭行为不变。没有新建或复制库存，也没有改配方、耐久、成本或机器名称。
