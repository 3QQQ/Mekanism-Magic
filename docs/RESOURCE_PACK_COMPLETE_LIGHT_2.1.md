# AE Terminal Complete 2.1 — 菜单透明背景修复

修复用户反馈的选项页／暂停菜单变成整块实心暗灰、完全挡住世界的问题。
2.0 生成器错误地把原生半透明菜单纹理填成了不透明纯色；上一轮的控件验收屏
自行绘制背景，未覆盖真实 `Screen.renderBackground` 路径，因此没有暴露这个问题。

## 变化

- 菜单背景保留原生透明度 64/255，列表背景 112/255，页签头 0/255。
  灰紫色调只改变 RGB，不再覆盖透明度；世界与标题全景仍由游戏原本的渲染／模糊处理。
- 三态原生按钮增加细亮边，避免和背后的灰色面混在一起。
- 滑块轨道与滑块手柄分别绘制，保留原生尺寸和交互位置。
- 相对 2.0，仅 12 张 `assets/minecraft/textures/gui/` 贴图改变；资源路径没有增加或删除，
  AE2、JEI、Mekanism 和辅助模组的其他界面材质保持不变。

## 验证

IDEA 已连接主项目。静态检查、73 份九宫格、1,502 张资源加载与 450 张原版 GUI 图集
检查通过。新增透明度断言，255 的实心菜单背景会使检查失败。

验收客户端在自己的 `build/ui-pack-client/` 目录创建临时超平坦世界，真实打开并截图：

1. 标题画面进入的原生选项页（可见全景图）。
2. 世界内原生暂停菜单（可见草地、天空及玩家视角）。
3. 世界内原生选项页（可见同一世界）。

这三项使用原生 `OptionsScreen` / `PauseScreen`，未覆盖其背景渲染。
同时检查菜单之外的截图区域不再是单一纯色、原生按钮三态的文字像素仍然存在。
测试结束后客户端和集成服务器已自动退出，未操作用户当前游戏实例或存档。
其他辅助模组仍沿用 2.0 的资源级检查边界，不声称已逐个游玩实测。
