# AE Terminal Complete 2.2 — 原包参数、Mek 亮色、纯资源包

用户最终确认：参考 CozyUI+ 各种参数，制作与既有 Mek 亮色材质同风格的包；
明确不增加客户端文字配色补丁。本次按此范围实施，没有改运行时代码或模组版本。

## 与 2.0/2.1 的区别

不再用自绘矩形按钮覆盖参考参数，也不再为了原生白字把普通按钮改成深灰。
保留参考 PNG 的原尺寸、完整动画图、逐像素透明度、圆角和阴影轮廓，
只按控件材料角色映射为 Mek 亮色色表。普通按钮中心实测 RGB 为
`176,178,196`，即 `#B0B2C4`；悬停映射为冰蓝，禁用、轨道和手柄分别处理。

87 份原包元数据逐字节不变；保留 75 组九宫格和 21 组动画参数。
唯一兼容修复是 `trial_available` 只有 0–5 六帧却引用帧 6，删除了该越界引用，
不改其余帧序列、时长或材质图。

Mek 系列沿用 1.8 亮色图；AE2 原色不重复染色。原生白字／灰字保持不变，
不注入字体、语言、shader 或 JAR，因此不声称获得深底白字版本的对比度，
也不声称解决 QIO/RGB 等硬编码文字问题。
