# Mekanism Magic 1.0.6.49 — 撤销秘法赋能台

本轮按用户要求，从主开发树撤销本附属的 `item_modifier_processor`。
这是可选 Forbidden & Arcanus 适配中的机器，不是原模组自己的锻造修饰配方或工作台。

## 变更范围

- 移除方块、物品、容器和方块实体注册；创造栏、客户端界面注册及专用 JEI
  类别、催化物、配方页和运行时刷新入口不再提供。
- 移除对应合成、掉落、方块状态和模型的打包输出，并从中英文语言表、采掘
  标签及机器契约中移除该 ID。Forbidden 普通机器由六台减少到五台。
- 原模组的 `ApplyModifierRecipe` 六条配方、原生工作台及读配方所需的
  版本桥接保持可用。赫菲斯托斯锻炉、燃烧、灵魂提取、模拟采血、经验装瓶
  及此前的自然灵气适配不受此次取消影响。
- 旧机器源码、六份专属资源及两组历史 GameTest 均已删除，
  不保留可复用实现副本；主源码、测试编译及 JAR 均不包含这台机器。

## 旧测试世界

`1.0.6.48` 开发测试包曾包含这台机器。若测试存档已放置它，使用新包前
需先以旧包拆除机器并取回输入、升级与产物；取消注册后原方块 ID 不再可加载，
机器内部的 `item_modifier_machine` 已付费或待输出数据也不会自动迁移。
原 `1.0.6.48` 包保持不变，供回收旧测试存档使用。

## 验证

- 离线完整 `check -x jar -x validatePackagedIntegrations` 通过，机器契约
  为 54 台，双语标题仍一致。
- Forbidden 独立 GameTest 109/109 通过，包含机器 ID 不再注册的检查；
  原生修饰配方目录仍被测试。早期三项失败断言原本要求本附属继续展示
  修饰 JEI 页面，已按取消后的行为更新。
- Nature-only GameTest 67/67 通过，相关工厂、管道和菜单布局没有回退。
- `assemble validatePackagedIntegrations`（完整集成检查）通过；开发 JAR
  内无秘法赋能台的类、配方、模型或方块资源。
- 旧 `1.0.6.48` 开发包、`1.0.6.47` 修复包及历史发布均未覆盖或上传。

本轮改变机器注册与实际运行时代码，通过测试后开发号从 `1.0.6.48`
递增一次到 `1.0.6.49`。这不是正式发布。
