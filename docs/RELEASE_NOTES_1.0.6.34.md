# Mekanism Magic 1.0.6.34（未发布开发版）

## 常驻物品侧栏

按粉笔槽的交互方式，为机器右侧增加“常驻组件”展开/收起页。初始收起，
点击末影之眼图标后取放；配方耗材、产物、能源物品和升级槽保持原位置。

- 魔灵驱策台及八档魔灵工厂：常驻魔灵。
- 维度采掘井：矿工组件；秘仪演算核心：微缩法阵，侧栏与原辞典页互斥展开。
- 自然灌注祭坛及八档自然祭坛工厂：催化剂；诸神祭祀台：可选凋零玫瑰。
- 德格米共生舱：九个生物样本槽。
- 克里巴诺秘炉：增强物；灵魂萃取仪：工具；血源凝炼器：血液样本。
- 赫菲斯托斯锻造台：核心、启动工具、四个增强槽；等级锁和核心升阶托管提示保留。
- 魔源灌注室及八档灌注工厂：将催化剂选择框并入原催化剂库顶部，右键清除和 JEI
  拖入都使用新位置；收起库或打开 ME 样板窗口时，选择框不可操作。

共有 26 个机器/工厂菜单的 39 个原始物理槽使用共用侧栏；另有九个灌注界面
调整选择框。原粉笔、辞典和分页催化剂库存不重建，不产生重复物品。

## 数据与兼容边界

界面只移动同一个菜单 Slot 的客户端坐标；关闭恢复原位置。收起同时隐藏边框和
禁用该槽的客户端命中检测。物品身份、组件、槽索引、机内库存、NBT、取放限制、
自动化、配方数量及工具耐久损耗不变；不改服务端加工、价格或存储格式。
共用 Slot 钩子在未被本附属界面显式启用时不改变任何槽的行为。

灌注机选择框不再占用主加工区，库中原 16 个窗口槽、分页顺序和底部边界保持原样。
普通机和工厂继续使用已有主题与统一标题，不改机器名称或玩家自定义名称。
