# 1.0.6.61 — 保留统一风格的信息仪表

按用户澄清重新调整两台样板：保留原有统一界面风格，只改善信息组织。
不再使用 `1.0.6.60` 样板的原版灰壳或独立黑底读数框。

## 本轮运行时改动

- 灵气凝聚器与赫菲斯托斯锻造台重新使用统一背景、配色、字体、边框及侧栏。
  恢复原有主题切换按钮和共享标题/状态渲染，增强器侧栏也回到统一面板样式。
- 新 `GuiMachineInstrument` 保留短标签、单位、数值与完整悬停信息；透明背景直接使用
  原工作区底色，文字取统一主题的 `textMuted` / `textPrimary`，仅用细分隔和细进度条组织信息。
- 不再硬编码黑色 LCD、原版灰壳或专用文字颜色。默认和终端资源包的深浅主题均按原有 palette 渲染。
- 删除已取消的 `MekIndustrialScreen`、`GuiMekMachineReadout` 和共享入口中的原生皮肤旁路；
  保留负向测试及打包检查，防止旧实现或增量编译残留重新进入 JAR。
- 仅两台样板使用新仪表，其它机器原有展示保持不变。
  所有菜单槽位、背包坐标、配方、生产、资源传输、注册 ID 和存档数据均未改变。

本轮相对 `1.0.6.60` 有上述实际客户端渲染代码变更，验证后仅递增一次开发编号到 `.61`。
历史 `.60` JAR 和截图保留，不覆盖、不发布正式版本或远程标签。
