# Mekanism Magic 1.0.6.35（未发布开发版）

## 区分神秘学仪式刷怪蛋

修复同一个通用物品共用名称、外观，且 JEI 未注册实体/职业子类型，导致仪式刷怪蛋
难以辨认、配方查询混在一起的问题。

- 默认名称直接显示目标实体及魔灵职业，例如“魔精·慢速碎矿者仪式刷怪蛋”、
  “巨灵·铸晶者仪式刷怪蛋”。实体和职业名称复用所装 Occultism 1.222.0 的翻译。
- 壳色区分魔灵种类/阶级，斑点区分碎矿、铸晶、熔炼等职业；其他实体使用确定性配色。
  图形使用原版刷怪蛋的两层染色遮罩，不额外生成或覆盖第三方贴图。
- 普通、小型、特殊、水生、可骑乘动物，以及村民随机范围使用独立的中英名称。
  随机、绑定、复苏和概率结果有明确标记；概率召唤提示其失败分支会生成鸡。
- JEI 的现代与兼容子类型接口共用同一身份：目标实体/标签、职业、归属模式、
  概率、召唤之书及其余实体特征。玩家取名、生成的魔灵名字、UUID、数量和坐标
  不制造额外配方类型。不同实体、职业与阶级不再共用一个配方查询结果。
- 从真实可用配方产物中加入可搜索刷怪蛋条目，同类结果去重；重载数据包时增删对应
  条目，退出 JEI 时清空状态，不保留已移除配方的旧蛋。

本次只读取旧蛋已有的数据决定显示与 JEI 身份；不写入额外名称/颜色组件，不改刷怪蛋
注册 ID、实体数据格式、叠放规则、召唤概率、职业初始化、归属、配方、材料或消耗。
旧格式的职业/主人字段继续识别；铁砧名称及明确的 ITEM_NAME 组件优先。
自然灵气自己的刷怪蛋保留原命名与配色入口。
