# Mekanism Magic 1.0.6.27（未发布开发版）

## 禁忌奥秘精华制备

完成用户指定的三机制作，其中血液改为模拟击杀、经验改为玩家存储后装瓶。不是上一份方案中的世界攻击采血或石化经验球凝聚。

| 机器 | 操作 | 基础功率 / 时间 |
| --- | --- | --- |
| 灵魂提取机 `soul_extractor_processor` | 1灵魂沙→1原版灵魂+1失魂沙；保留一件原版灵魂提取器，每次原生损耗1耐久 | 50 J/t / 35tick |
| 模拟采血机 `simulated_blood_extractor` | 保留收容样本，重复模拟获得血；消耗1空试管装填固定3000血试管 | 模拟1000 J/t / 200tick每轮 |
| 经验装瓶机 `experience_bottler` | 15点储存玩家经验+1玻璃瓶→1原版附魔之瓶 | 100 J/t / 40tick |

以上功率单位为Mekanism J；默认2.5 J/FE时分别20、400、40 FE/t。沿用原生速度/能量升级公式，原料单次产量不因升级增倍。模拟产血的装瓶只消耗已经付费产生的缓存，不再重复收取模拟费用。

### 模拟采血

- 收容生物作为保留样本，支持现有共享生物容器适配器；不接受空容器、刷怪蛋、玩家或非生物样本。
- 每轮产量取生物类型默认最大生命值×20向下取整，最高3000。保存的Health/Attributes不能抬高产量；原版TEST_TUBE_BLACKLISTED标签继续生效，重载加入/移除均重新判定。
- 不把样本实体放入世界，不触发真实伤害、死亡、战利品或经验流程。此为用户指定的模拟生产机制，不宣称是原版实体死亡处理。
- 血液容量30000。没有试管时可积累到容量上限；产物槽满或不兼容时停止继续模拟。样本更换清当前进度，已生成血不丢。
- 只有足够3000血时才消费一个真实空试管；输出使用原版ESSENCE_STORAGE组件，抽空按原版规则返空管。余量留在缓存，产物没有随机UUID、时间戳等额外标签。

### 玩家经验存取

- 玩家主动点击存入/取回10、100或全部；按经验点而非等级计算，不在机器tick扫描或抽取任何玩家。
- 机器容量1000000经验。按level+经验条重建实际点数，不信任可能已漂移的totalExperience；余额不足或仓满只移动可用数量。不可表示的异常经验状态拒绝操作，不直接归零或截断。
- 菜单和服务器校验当前容器、距离、世界、机器实例、访问权限及玩家状态。禁止创造模式/旁观者存入；多玩家操作仍只转移实际剩余余额。
- 投入加工前只扣一次15经验与空瓶，保存已付款产物；中途断电、红石停机、堵塞、重载和拆机重放不重复扣费。尚未投入加工的经验可取回。
- 原版附魔之瓶给禁忌奥秘锻炉提供15经验精华；投掷后的普通XP仍遵循原版随机值，机器不更改药瓶本身行为。

### 资源、界面与边界

- 三台机器均已加入注册、创造页、合成配方、双语GUI、掉落、挖掘标签、Mek侧面配置、默认六面能量输入和顶部物品口；特殊工具/样本不可被外部抽走。
- 新增三个JEI制备类别。经验点不是伪造的物品材料；空量子捕捉器仅用RENDER_ONLY图标说明保留样本要求，不当作可用输入或AE耗材。血液页明确每轮产血量不同，200tick不等于每满管时间。
- 三个新单方块模型分别为提取塔、模拟舱/试管架、经验储罐/装瓶台，沿用F&A材质引用。待机/工作状态独立，无新增纹理文件、世界粒子或前台建模操作。
- 耀金瓶保留原版普通合成，不额外添加一份相同配方。本轮不增加工厂、精华管道、FE直接转换精华或专用AE样板。
- 精确依赖仍为Forbidden & Arcanus2.6.1 + Valhelsia Core1.1.5，平台Minecraft1.21.1/NeoForge。
